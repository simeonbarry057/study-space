# CCNA Study Site Constitution
## Purpose
This constitution is the set of rules Claude follows when looking after the CCNA Study Planner: the published site and the code behind it. Simeon owns it and can change any rule at any time. Claude reads the latest version at the start of every review.
## Rules
1. Every 3 hours, Claude reviews this Constitution, confirms every rule is being followed, and sends one short email to Simeon once the review is finished.
2. Every review checks the code and the website for bugs and errors, and confirms the site is working properly.
3. Once a day, at the end of the day (about 9:00 pm Guyana time), Claude sends a Daily Report email. That email includes a PDF of the CCNA Study Site Blueprint, the running record of every command and request Simeon gives Claude. The 3-hourly emails do not carry the PDF.
4. Every email Claude sends carries the Gmail label "GdTHat Claude Project" and is kept out of the main inbox.
## Major Orders
Big, lasting commands for what the study site must do. Each review checks every one against the live site and reports it as Working, Pending or Broken.
1. **Security code.** Sign-ups get a pop-up with a 5-digit security code and must confirm they wrote it down. Customers can view their code in Account settings after re-entering their password. Accounts created before this have no code. If a person reaches out, Simeon can generate a new code, which is emailed to them (and shown to Simeon), and he can view anyone's current code from the admin area in case they say they never received it.
2. **Password reset by email.** Forgot password emails a link that asks for the 5-digit code, then a page to enter and re-enter a new password. A link works once for 1 hour.
3. **Lockout.** After 5 wrong codes the account is locked and shows Blocked in the admin area, where Simeon can unlock it or issue a new code. Simeon is emailed when an account locks.
4. **Expiry reminders.** Customers are emailed 10, 5 and 3 days before access ends and when it ends. Simeon is notified 3 days before and on the day, under the label GdTHat Exp Notices.
5. **Sign-up alerts.** Simeon is emailed immediately on every sign-up, under the label GdTHat Study Space: new sign-ups.
6. **Free first lesson and locked lessons.** New sign-ups get the first lesson free; the rest stay locked on the server until approved. Clicking a locked lesson shows a pop-up naming the free lesson.
7. **Owner-only notebook editing.** Only the owner can edit the notebook pages. Admins and learners cannot.
8. **Off-site backup.** All accounts, access records and progress are copied to Google Drive every day.
9. **Payment path (PENDING).** MMG number and administrator contact are blank until Simeon supplies them.
10. **Content improvement (IN PROGRESS).** Polish remaining lessons, write missing quiz questions, check exam-domain percentages, add a timed practice exam and cheat sheets, bring back the interactive Excel formula sheet.
